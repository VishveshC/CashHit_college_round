## Phase 3 implementation clarification

A-28 through A-35 implement the local arbitration decisions. Randomness callbacks only store entropy; permissionless advance consumes it and starts the replacement commit window, superseding the callback-assignment wording of G-06. Draw candidates are frozen before the first request and retained across retries. A short initial/second pool reaches fallback only after accepted entropy, while provider failure still uses all bounded attempts. Registry and adapter remain local prototype mechanisms; G-05 production integration is unresolved. Final measured evidence is in PHASE3_REPORT.md.
